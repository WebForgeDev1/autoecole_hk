# Illustrations temporaires

Créées avec le générateur intégré Imagegen. Scènes fictives, sans témoignages réels.

Prompts utilisés :
1. Photographie naturelle : élève adulte et moniteur souriants auprès d’une voiture garée dans une rue française, lumière douce, sans texte ni logo.
2. Photographie naturelle : élève adulte au volant d’une voiture garée avec son moniteur, vue depuis la fenêtre, sans texte ni logo.
3. Photographie naturelle : deux élèves adultes et leur moniteur près d’une voiture dans une petite ville française, sans texte ni logo.

Remplacer ces images par les photos réelles autorisées lorsqu’elles seront disponibles.

## Règle de placement

Chaque sticker est réservé à un seul emplacement dans l’ensemble du site. Ne jamais réutiliser un sticker dans une autre section ou page. Créer une nouvelle illustration distincte dans le même style pour tout nouvel emplacement.

14 illustrations supplémentaires réalisées avec le générateur intégré Imagegen : compteur et loupe, cadeau de parrainage, dossier administratif, bulle de contact, appareil photo, trophée, analyse de parcours, carnet de progression, statistiques, levier manuel, sélecteur automatique, conduite accompagnée, route supervisée, ordinateur pour le code en ligne.

Fichiers : sticker-unique-*.png. Prompts et sources de génération conservés dans sticker-pack-manifest.json.
